# Genetic Algorithm ML Playground

This project explores how genetic algorithms can be used for machine learning optimization tasks.

## Topics
- Function optimization
- Feature selection
- Hyperparameter search
- Genetic programming basics

## Tools
- Python
- NumPy
- scikit-learn
- PyGAD
- DEAP

## Experiments
1. Optimize a mathematical function with GA
2. Use GA for feature selection
3. Use GA for RandomForest hyperparameter tuning
4. Compare GA search with random search
